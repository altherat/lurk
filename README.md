# Lurk

A Reddit and Digg app for Android and iOS created with Flutter. Heavily inspired by Reddit is Fun (RIF).

## Disclaimer
Reddit has made efforts to phase-out third party apps and Digg very recently relaunched so I wouldn't be surprised if things break or requests get blocked.

It's called Lurk because I wasn't planning on adding logging into Reddit/Digg. I created this mainly out of boredom and designed the functionality around how I personally use RIF. Logging in isn't too important to me but I will probably work on adding it as well.

## Versions
There's 3 versions/APKs available with each release - a standalone Reddit app, a standalone Digg app, and one that combines both.
